# Brand names

Proposals for the public name of the CI regression gate. Web search on 12 October 2026. This is a conflict scan, not a trademark search, a domain check, or legal advice.

The repository name and the live URL stay `agent-regression-gate` (`https://ryean0.github.io/agent-regression-gate/`).

## Top pick: Mullion

The bar that divides a window so the two panes can be compared. Short, one word, and it matches a paired baseline and candidate without sounding like a dashboard.

**Conflicts found:** [eMullion](https://www.emullion.com/) (also written up on [Crunchbase](https://www.crunchbase.com/organization/emullion)) is estimating and project software for door, frame, and hardware distributors. A facade engineering calculator in closed testing uses “mullion/transom” as a common noun, not as a developer-tool brand. No developer-platform company under the exact name Mullion turned up in this search. eMullion is the obvious nearby hit, in a different market.

Applied on the site: document title, Open Graph and Twitter titles, JSON-LD name, nav wordmark, hero eyebrow, footer wordmark, and the pilot email subject. Body copy that used the old product name now says Mullion.

## Shortlist

1. **Mullion.** Paired panes, one divider. Top pick. Conflict: eMullion door-hardware software; a facade calculator uses the common noun.
2. **Sill.** The threshold a change has to cross. Immediately clear. Conflict: [The Sill](https://www.thesill.com/), the houseplant retailer, owns the consumer search.
3. **Lintel.** The beam that carries the load over an opening. The metaphor is exact. Conflict: [lintel.software](https://lintel.software/) is a live custom-software business using that same metaphor; the [npm package `lintel`](https://www.npmjs.com/package/lintel) is an older CSS framework at lintel.io; Lintelio is a separate company name in business directories.
4. **Quoin.** The dressed stone that locks a corner. Compact and serious. Conflict: [Quoin, Inc.](https://quoininc.com/) has built software in Boston since 1994, so “Quoin software” already means them.
5. **Plinth.** The base a measurement stands on. Calm, slightly abstract. Conflict: [Plinth](https://www.useplinth.com/) is a philanthropy and grants-management product in the US and UK.
6. **Transom.** The window above a door: you look through before you open. Conflict: a [Mac menu-bar app](https://gettransom.app/press), a [writer’s notes app](https://apps.apple.com/us/app/transom-note-taker-for-writers/id927983947), [Craft and Shopify plugins](https://transom.dev/), and Transom.org in public media. Too many existing products.
7. **Holdfast.** A clamp that holds the work while you check it. Plain English. Conflict: [holdfast.dev](https://holdfast.dev/) is a small AI and micro-SaaS shop, which sits in the same neighborhood as this product.
8. **Fairlead.** A guide that keeps a line from chafe. Nautical and tidy. Conflict: [fairlead.dev](https://fairlead.dev/) is an ad-exchange API with first-party SDKs, and [Fairlead](https://fairlead.com/about/) is a large shipbuilding company.

## Set aside before the shortlist

**Harness**, the name on the page before this change, is [Harness Inc.](https://www.harness.io/), a CI/CD platform. That collision is why the wordmark moved.

**Pintle** (the pin a gate hangs on) was a strong metaphor and lost on the search: [pintle.app](https://pintle.app/) is already a parent brand for desktop tools aimed at technical teams.

## How the pick was applied

Mullion replaces the product name in the title, nav, hero, meta tags, footer, and the pilot mailto. The GitHub Pages URL, the `agent-regression-gate` folder, and the source link are unchanged. The results reader and `results.schema.json` were not edited for the rename.
