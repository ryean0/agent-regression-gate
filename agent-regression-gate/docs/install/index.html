    Install and setup

    Initialize and run the harness, then read the suite status. The license is MIT. The repository is ci-agent-regression-harness (beta testing).

    Prerequisites

    The provider key is the environment variable GEMINI_API_KEY. Samples and this page use a placeholder. Do not commit a real key, and do not paste one into a workflow file.

    The language version and the package manager are the ones named on the harness main branch. Coming soon That list is not guessed here.

    Configure the provider key

    Put the key in GEMINI_API_KEY before a run that calls the provider. The line below is a placeholder for samples. It is not a live credential.

    environment · placeholder

    GEMINI_API_KEY=your-key-here

    Run the sample suite Coming soon

    The sample suite, including an offline run, is Coming soon. The command is omitted until main publishes it.

    Read the verdict Coming soon

    The command that prints the verdict is Coming soon, for the same reason.

    When a run does print a suite status, read it as one of three: Pass, Block, or Insufficient evidence. likely_regression is a warning. It is not a status. An invalid run is not scored. Scenario rows stay diagnostics. The rule is on Concepts.

    Enterprise and CI

    The packaged GitHub Action is Coming soon. The target is milestone M3.

    No workflow from the harness main branch is copied here. A sample workflow is not guessed. The CI reference is the contract this site already states: the job can be required only when it runs on a pull request, and it does not store a cloud key.

    • The provider key is a repository secret. Keep it out of the workflow file.
    • Keyless OIDC. The job asks GitHub for a short-lived token. It does not store a cloud key.
    • Spend cap. Example CI stops at $38. Example An alert is set at $40. The stop is the same idea as spend governance. The figure there is an example, not a price for every install.
    • A pull request from a fork never receives repository secrets.
    • A run that spends money is manual, and a reviewer has to allow it.

    Troubleshooting

    • Missing key. GEMINI_API_KEY is unset or empty, so a provider call cannot start. Set the variable in the environment. Keep the real value out of the repository. The placeholder is your-key-here.
    • Spend cap stop. Recorded spend reached the stop, so the run halted. Example The stop is $38. Example The alert is $40.
    • Insufficient evidence. The interval does not support Pass, and it does not support Block. likely_regression on that result is a warning, not its own status. Read the statuses on Concepts.
