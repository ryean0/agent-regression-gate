About

Public beta

Anubys is a CI-native agent regression harness.

It runs in the pull request. The candidate and the baseline face the same scenarios, and the merge gets a statistics-backed check.

Get started Read the method

The problem

Regressions stay quiet.

An LLM agent can regress when a model, prompt, or tool changes. Ordinary tests miss the drop. Reading a few transcripts misses it too. Teams ship without a signal, or they hold the change on too little evidence.

What Anubys does

A merge check, with a verdict.

In CI, Anubys runs the candidate and the baseline on paired scenarios. The pull request receives one statistics-backed verdict.

  • Pass

  • Block

  • Insufficient evidence

  • Invalid run
