Technical details

The adapter contract is provider-agnostic, and it is the intended seam. This repository does not ship an adapter. One rollout is one call: scenario id, SHA-256 of the scenario text, arm (baseline or candidate), and a step budget. The adapter returns pass, fail, agent timeout, or an infrastructure miss. An agent timeout scores 0. A provider error, a rate limit, or a killed runner is excluded from the score and counted toward the 5% miss cap. The model name does not enter the suite verdict.

First backend, in progress. The harness calls a pinned Gemini Flash-Lite model id (exact version set in suite config). That version is not final. A floating alias is not the pin, because it moves. The adapter stays labeled in progress until it merges. OpenAI Agents SDK, Claude Agent SDK, LangGraph, LlamaIndex, CrewAI, AutoGen, and Microsoft Agent Framework are roadmap adapter examples, not backends in development, and not partnerships.

The scorer does not import an agent SDK. It pairs scenarios, builds the 90% interval, and the check fails on Block. Scenario rows stay diagnostics. They are not individual gates.

GitHub Action, planned. Trigger pull_request so the check can be required. The job runs both arms through the adapter and uploads results.json. It fails the check on Block. An invalid run is reported as invalid and isn't scored. A merge queue would also need the merge_group event. Buildkite, Jenkins, and your own runner are the same planned job, not separate products.

Record/replay cassettes: In review, on harness #14. Not merged yet. Record mode would store model and tool traffic keyed by the scenario hash and the arm. Replay mode would return that recording and would not call the provider. A hash mismatch is a miss, not a silent reuse. A cassette is an input to scoring. It is not a verdict.

OpenTelemetry GenAI spans, planned. If an agent already emits them, an adapter may attach the trace as a diagnostic. Spans do not set the suite status. Those semantic conventions are still marked Development. Inspect, promptfoo, LangSmith, Braintrust, and DeepEval are planned sources of scenarios or scores. They do not become the suite verdict.
